# Radares

`cs2a radars` (o el botón en la app) descarga acá las imágenes de radar y `map_data.json` desde
[awpy-data](https://github.com/pnxenopoulos/awpy-data). No se versionan porque son assets de Valve.

También podés poner tus propios PNG de 1024x1024 con el nombre del mapa (`de_mirage.png`, `de_nuke_lower.png`).
